# Orchestration scaffold

The workflow map describes seven logical stages:

1. capture;
2. normalize;
3. structure;
4. reconcile;
5. govern;
6. project;
7. learn.

Each stage defines purpose, owner, inputs, outputs, completion criteria, and blockers.

The map is implementation-neutral. It does not select a workflow engine, queue, scheduler, database, model provider, or user interface.
