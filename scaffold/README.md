# Scaffold

The scaffold makes the GTM Brain operating model concrete without implementing it.

## Areas

| Directory | Purpose |
|---|---|
| `ingestion/` | Team source manifests and the common source-intake contract |
| `knowledge/` | Linked Source, Evidence, Audience, Insight, Claim, and Message examples |
| `governance/` | Review and lifecycle-policy examples |
| `orchestration/` | Logical stage map from capture through feedback |

All files are illustrative placeholders.

They do not connect to external systems, process customer data, call a model, or produce assets automatically.
