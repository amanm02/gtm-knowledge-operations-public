# Illustrative outputs

The files in this directory show one shared knowledge chain projected into three team-specific asset formats.

They are static examples, not an execution flow.

Every example is labeled:

```text
ILLUSTRATIVE OUTPUT — PLACEHOLDER CONTENT ONLY
```

## Shared chain

`shared/knowledge-chain.example.json` links:

```text
Source
→ Evidence
→ Audience and Insight
→ Claim
→ Message
→ Marketing, Sales, and CX Asset records
```

## Team outputs

- `marketing/content-brief.example.md`
- `sales/objection-handling.example.md`
- `cx/voice-of-customer-summary.example.md`

All three outputs reuse the same Source, Evidence, Audience, Insight, Claim, and Message IDs. This demonstrates that GTM Brain is the core shared product and the team assets are projections.

No file represents a real customer, company, campaign, call, support issue, outcome, or approval.
